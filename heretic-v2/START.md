# Heretic — pacote de implementação

Ordem de criação obrigatória: 01 → 46. Um commit por bloco.

Regras para quem executa:
1. Copie cada arquivo byte a byte. Não reescreva, não "melhore".
2. Persona e contract em pt-BR.
3. Faltando informação, escolha a opção mais próxima e anote no fim.
4. Não renomeie rota, variável, arquivo ou código de erro.
5. Antes de cada bloco, liste os arquivos. Depois, mostre o diff.
6. Rode `npm run build` depois dos blocos 20, 30 e 40. Build vermelho = pare e corrija.
7. Só comece o bloco seguinte com o anterior verde.

Nada aqui é opcional. `RUNBOOK.md` e `DOD.md` são critério de aceite, não leitura.
